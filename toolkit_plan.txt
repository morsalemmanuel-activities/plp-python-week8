
PERSONAL MINI-TOOLKIT PLAN

Project Name: Personal Mini-Toolkit

TOOLS

1. Simple Calculator
This tool asks the user for two numbers and an operation, then displays the result.

2. To-Do List Manager
This tool allows the user to add, view, and remove tasks using a Python list.

3. Even-or-Odd Checker
This tool asks the user for a whole number and determines whether it is even or odd.
